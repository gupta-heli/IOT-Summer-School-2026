## Q29. Sensor Calibration in IoT Systems

### What is Sensor Calibration & Why is it Important?
Sensor calibration is the process of comparing a sensor's raw output values against a known standard or reference to establish a relationship, adjusting the readings to match the physical truth. 
* **Importance:** In IoT, calibration is critical because sensors suffer from manufacturing variances, aging, ambient temperature offsets, and electrical noise. Uncalibrated sensors lead to drift and inaccurate data, potentially causing system failures (e.g., over-watering plants, false fire alarms).

### Calibrating an Analog Soil Moisture Sensor (Two-Point Method)
An analog soil moisture sensor reads raw voltage (represented as `0` to `1023` in Arduino's ADC). To map this raw reading to a meaningful moisture percentage (0% to 100%), we use the **Two-Point Calibration Method**:

1. **Step 1: Obtain the Dry Point (0% Moisture)**
   * Keep the sensor dry in open air.
   * Read the analog value (e.g., it reads `850`). This represents **0% moisture** (completely dry).
2. **Step 2: Obtain the Wet Point (100% Moisture)**
   * Fully submerge the sensor probe in a glass of water up to the maximum line.
   * Read the analog value (e.g., it reads `290`). This represents **100% moisture** (completely saturated).
3. **Step 3: Map in Code**
   * Since higher water content decreases the resistance and thus lowers the analog voltage read, the mapping is inverted.
   * We apply the `map()` or linear interpolation formula in the Arduino code:
     ```cpp
     int rawVal = analogRead(sensorPin);
     // Map raw values (850 is dry/0%, 290 is wet/100%)
     int moisturePct = map(rawVal, 850, 290, 0, 100);
     moisturePct = constrain(moisturePct, 0, 100); // Keep within bounds
     ```

## Q30. The I2C Protocol in IoT Sensor Communication

### What is I2C?
I2C (Inter-Integrated Circuit) is a synchronous, multi-master, multi-slave, packet-switched serial communication bus. It is widely used in IoT to connect low-speed peripheral ICs (sensors, displays, RTCs) to microcontrollers over very short distances.

### The SDA and SCL Lines:
* **SDA (Serial Data Line):** The bidirectional line over which data is sent and received between master and slave devices.
* **SCL (Serial Clock Line):** The line carrying the clock signal generated by the master device to synchronize data transfers.
*Both lines require pull-up resistors (typically 4.7kΩ to 10kΩ) connected to VCC to keep the bus lines HIGH when idle.*

### How I2C Addressing Works:
* I2C uses an address-based signaling mechanism. Instead of using separate Select lines for each device (like SPI does), all slave devices share the same SDA and SCL wires.
* Each slave device is assigned a unique 7-bit (or 10-bit) hardware address (e.g., `0x27` for an LCD, `0x68` for an MPU6050).
* When the master wants to communicate, it sends a **Start Condition** followed by the 7-bit target address and a Read/Write bit (8 bits total). 
* The slave device matching that address responds with an **Acknowledge (ACK)** bit, while other devices ignore the rest of the transaction.

### 3 Common IoT Sensors that use I2C:
1. **MPU6050** - 3-Axis Gyroscope and Accelerometer IMU.
2. **BMP280 / BME280** - Barometric Pressure, Temperature, and Humidity sensor.
3. **BH1750** - High-resolution digital ambient Light intensity sensor.
