# Repository Branching Strategy

This repository follows a structured branching model to manage development workflow for the IoT Summer School coursework:

- **`main`**: The primary production-ready branch. It contains only stable, tested, and finalized coursework submissions.
- **`dev`**: The integration branch. Features from individual module branches are merged here for validation, testing, and documentation writing before being merged into the `main` branch.
- **`sensor-module`**: Dedicated feature branch for developing and testing sensor interface logic, driver libraries, and data acquisition (Module 3).
- **`wireless-module`**: Dedicated feature branch for implementing wireless communication protocols, Wi-Fi connections, and API integrations (Module 4).
